# Campaign Brain

The "marketing brain" is a set of JSON files under `campaigns/`, `formulas/`,
`personas/`, and `seasonality/`, generated by
`scripts/generate_marketing_brain.py`. It contains:

- **50 campaigns** — distinct angles/offers for Prayonit.
- **15 formulas** — copywriting structures (e.g. PAS, AIDA, before/after).
- **15 personas** — target-audience voices/tones.
- **31 seasonality entries** — dated or rule-based contexts (holidays,
  Easter-relative dates, nth-weekday holidays like Mother's Day, and
  season windows).

## Schema (per campaign JSON)

```json
{
  "id": "campaign_slug",
  "name": "Human Readable Name",
  "angle": "Short description of the marketing angle",
  "hook": "A specific hook/opening idea",
  "cta_style": "soft" | "direct" | "urgent",
  "weight": 1.0
}
```

Formulas and personas follow the same idea (`id`, `name`, descriptive
fields, `weight`). Seasonality entries additionally include a `rule`:

```json
{
  "id": "mothers_day",
  "name": "Mother's Day",
  "rule": {"type": "nth_weekday", "month": 5, "weekday": 6, "n": 2},
  "weight_boost": 1.5
}
```

Rule `type` values:

- `fixed` — `{"month": M, "day": D}`
- `easter_relative` — `{"offset_days": N}` (N can be negative), computed via
  the Anonymous Gregorian algorithm in `campaign_engine.easter_sunday()`.
- `nth_weekday` — `{"month": M, "weekday": W (0=Mon), "n": N}`
- `season` — `{"start_month": M1, "start_day": D1, "end_month": M2, "end_day": D2}`

## Selection logic (`campaign_engine.py`)

1. Load all campaigns/formulas/personas via `load_*()`.
2. Determine `active_seasonal_contexts()` for "today" (Eastern time).
3. For each of campaign/formula/persona/background, `choose_*()`:
   - Pulls recent history (`history_store.get_recent_*_history()`).
   - Excludes anything used in the last N runs (configurable via
     `HISTORY_AVOID_LAST_N_*` env vars).
   - If exclusion empties the pool, logs that the rule was relaxed and
     retries with a smaller N, down to 0 (never crashes).
   - Applies `weight` and any active seasonal `weight_boost`, then picks
     via `_weighted_choice()` (a plain weighted-random selection).
4. `choose_selection()` bundles campaign+formula+persona+background+season
   context into one object for `prompt_builder.build_prompt()`.

## Adding a new campaign/formula/persona

Two options:

1. **Regenerate**: edit the `CAMPAIGN_TABLE` / `FORMULA_TABLE` /
   `PERSONA_TABLE` / `SEASONALITY_TABLE` list in
   `scripts/generate_marketing_brain.py`, then re-run:
   ```bash
   python scripts/generate_marketing_brain.py
   ```
2. **Hand-author**: drop a new JSON file matching the schema above directly
   into `campaigns/`, `formulas/`, `personas/`, or `seasonality/`. The
   loaders read every `*.json` file in the folder, so no code changes are
   required.

## Non-repetition

`history_store.get_recent_campaign_history()` /
`get_recent_background_history()` read the `campaigns_used` /
`published_posts` tables to avoid repeating the same campaign or background
image too soon. This is what "gradual relaxation" protects against pool
exhaustion — with 50 campaigns this is unlikely to trigger in practice, but
the safety logic exists for smaller custom pools too.
